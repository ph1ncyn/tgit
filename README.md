# tgit

Удобный и функциональный git-терминал (TUI) с поддержкой мыши, входом через GitHub-токен
и целью со временем закрыть большинство типовых неудобств git (см. [INTERFACE.md](INTERFACE.md) —
полное описание задуманного интерфейса; в коде пока реализована часть из него).

## Требования

- **Go 1.24+** (собрать можно на любой ОС — сборка кроссплатформенная, без cgo)
- **git**, установленный и доступный в `PATH` (tgit использует системный git, а не переизобретает его)
- Терминал с поддержкой мыши и, желательно, кликабельных ссылок (OSC8) — iTerm2, Kitty, WezTerm,
  Windows Terminal, GNOME Terminal, современный macOS Terminal.app. В остальных терминалах всё
  работает, просто ссылка на экране входа не кликается и её нужно скопировать вручную.

## Установка одной командой

### Linux/macOS — `install.sh`

```sh
./install.sh
```

Скрипт сам проверяет наличие `git` и нужной версии `Go`, собирает tgit и кладёт бинарник
в `~/.local/bin/tgit` — после этого команда `tgit` доступна в терминале (если каталог не
в `PATH`, скрипт покажет, какую строку добавить в конфиг оболочки).

Варианты:

```sh
./install.sh --system         # поставить в /usr/local/bin (запросит sudo)
./install.sh --prefix=DIR     # поставить в произвольный каталог
./install.sh --help
```

### Windows — `install.ps1`

```powershell
.\install.ps1 -AddToPath
```

Проверяет `git` и нужную версию `Go`, собирает `tgit.exe` и кладёт его в
`%LOCALAPPDATA%\Programs\tgit` (без прав администратора). Флаг `-AddToPath` сразу
добавляет этот каталог в PATH текущего пользователя (реестр, HKCU) — без него скрипт
только покажет команду для ручного добавления.

```powershell
.\install.ps1                                # собрать, но не трогать PATH
.\install.ps1 -Prefix 'C:\tools\tgit' -AddToPath
.\install.ps1 -?                              # справка (Get-Help)
```

Если запуск `.ps1`-файлов заблокирован политикой выполнения:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -AddToPath
```

### Если недостающая зависимость

`git` или `Go` не найдены — оба скрипта останавливаются и подсказывают команду установки
под вашу ОС (`winget`/`choco` на Windows, `brew`/`apt`/`dnf`/`pacman` на Linux/macOS).

## Сборка вручную

Из корня репозитория:

```sh
go build -o bin/tgit .
```

Или через Makefile (то же самое, для текущей платформы):

```sh
make build
```

Бинарник появится в `bin/tgit` (`bin\tgit.exe` при сборке на Windows).

### Кросс-компиляция под все платформы сразу

```sh
make cross
```

Соберёт бинарники под Linux, macOS и Windows (amd64 и arm64) в `dist/`:

```
dist/tgit-linux-amd64
dist/tgit-linux-arm64
dist/tgit-darwin-amd64
dist/tgit-darwin-arm64
dist/tgit-windows-amd64.exe
```

Кросс-компиляция работает с любой ОС-хоста (Go сам подставляет нужный `GOOS`/`GOARCH`), собирать
на самой целевой машине не обязательно.

## Запуск

После `./install.sh` — просто `tgit` в каталоге нужного git-репозитория.

Без установки, прямо из собранного бинарника:

```sh
./bin/tgit
```

(На Windows: `bin\tgit.exe`.)

`tgit --version` печатает версию и завершает работу без запуска TUI — удобно для проверки,
что установка прошла успешно.

## Первый запуск и вход через GitHub

При первом запуске (если токен ещё не сохранён) tgit сразу показывает экран входа со ссылкой
на создание Personal Access Token:

```
https://github.com/settings/tokens/new?description=tgit-cli&scopes=repo,read:user
```

- Кликните по ссылке (если терминал поддерживает) или нажмите `Ctrl+O` — откроется браузер.
- Создайте токен с правом `repo`, скопируйте и вставьте в поле ввода.
- `Enter` — токен проверяется через GitHub API и сохраняется в системном хранилище секретов
  (Keychain на macOS, Credential Manager на Windows, Secret Service/dbus на Linux; если оно
  недоступно — в файле конфигурации с правами `0600`).
- `Esc` — пропустить вход и работать локально: GitHub не обязателен для базовых git-операций,
  войти можно позже клавишей `g`.

## Главный экран

Четыре панели: **Ветки**, **Файлы** (staged/unstaged/untracked), **Лог** коммитов и **Diff**
выбранного файла или коммита. `Tab`/`Shift+Tab` переключает панель, `↑`/`↓` (или `j`/`k`) —
навигация внутри неё; в панели Diff это скроллит содержимое.

| Клавиша     | Действие                                                        |
|-------------|-------------------------------------------------------------------|
| `Tab`       | следующая панель (Ветки → Файлы → Лог → Diff)                    |
| `↑`/`↓`, `j`/`k` | навигация в активной панели / скролл diff                   |
| `space`     | застейджить / убрать из индекса файл под курсором                 |
| `enter`     | в Файлах — то же, что space; в Ветках — checkout выбранной ветки  |
| `c`         | новый коммит (нужны застейдженные файлы) — открывает поле ввода   |
| `b`         | переключатель веток: фильтр по подстроке, `enter` — checkout, а если совпадений нет — создать и переключиться на новую ветку |
| `p` / `P`   | push / pull (использует сохранённый GitHub-токен для HTTPS-репозиториев на github.com) |
| `f`         | fetch --all                                                        |
| `s`         | **Stash** — список стэшей с превью изменённых файлов; `n` — новый стэш, `enter`/`p` — pop (достать и удалить), `a` — apply (достать, оставить в стэше), `x` — drop (удалить безвозвратно, с подтверждением) |
| `d`         | **Doctor** — сканирует репозиторий (сейчас: файлы macOS `._*`/`.DS_Store`, незаигноренные `node_modules`/`__pycache__`/`.venv`/... ) и чинит по подтверждению |
| `y`         | в Логе — скопировать полный хеш коммита в буфер обмена             |
| `r`         | обновить данные репозитория                                        |
| `g`         | войти в GitHub / сменить токен (недоступно внутри других диалогов) |
| `Ctrl+C`    | выйти                                                              |

Во всех диалогах (коммит, переключатель веток, Doctor, Stash) — `Esc` отменяет и возвращает
на главный экран.

## Мышь

Работает в любом терминале с поддержкой SGR/X10 mouse-репортинга (все терминалы из списка
в разделе «Требования») на Linux, macOS и Windows одинаково:

- **клик по панели** — переключает на неё фокус; клик по строке в Ветках/Файлах/Логе —
  выделяет именно эту строку (эквивалент `↑`/`↓`, само действие — как обычно, через `space`/`enter`);
- **клик по кнопке тулбара** — то же самое действие, что и её горячая клавиша;
- **колесо мыши** — прокручивает панель под курсором (не обязательно активную с клавиатуры) —
  так же в списках модалок (переключатель веток, Doctor, Stash);
- в модалках со списком (переключатель веток, Doctor, Stash) клик по строке тоже выделяет её.

Клик всегда только выделяет — деструктивные действия (checkout, commit, drop) остаются за
явной клавишей, случайный клик их не запустит.

## Разработка

```sh
go vet ./...      # статическая проверка
go build ./...    # сборка всех пакетов
```

Структура проекта:

```
install.sh                — установщик для Linux/macOS: проверка зависимостей, сборка, PATH
install.ps1               — то же самое для Windows (PowerShell)
main.go                  — точка входа
internal/gitrepo/        — обёртка над системным git (статус, ветки, лог, diff, коммит, push/pull/fetch, стэш)
internal/doctor/         — правила "Git Doctor" и их автофикс
internal/ghauth/         — проверка GitHub-токена, ссылка на его создание
internal/secret/         — кроссплатформенное хранение токена
internal/openurl/        — открытие ссылки в браузере по умолчанию
internal/ui/              — экраны на Bubble Tea (вход, главный экран, панели, модалки, стили)
```
