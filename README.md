# tgit

Удобный и функциональный git-терминал (TUI) с поддержкой мыши, входом через GitHub-токен
и целью со временем закрыть большинство типовых неудобств git (см. [INTERFACE.md](INTERFACE.md) —
полное описание задуманного интерфейса; в коде пока реализована часть из него).

## Требования

- **Go 1.24+** (собрать можно на любой ОС — сборка кроссплатформенная, без cgo)
- **git**, установленный и доступный в `PATH` (tgit использует системный git, а не переизобретает его)
- Терминал с поддержкой мыши и, желательно, кликабельных ссылок (OSC8) — iTerm2, Kitty, WezTerm,
  Windows Terminal, GNOME Terminal, современный macOS Terminal.app. В остальных терминалах всё
  работает, просто ссылка на экране входа не кликается и её нужно скопировать вручную.

## Установка одной командой (Linux/macOS)

```sh
./install.sh
```

Скрипт сам проверяет наличие `git` и нужной версии `Go`, собирает tgit и кладёт бинарник
в `~/.local/bin/tgit` — после этого команда `tgit` доступна в терминале (если каталог не
в `PATH`, скрипт покажет, какую строку добавить в конфиг оболочки).

Варианты:

```sh
./install.sh --system         # поставить в /usr/local/bin (запросит sudo)
./install.sh --prefix=DIR     # поставить в произвольный каталог
./install.sh --help
```

Если недостающая зависимость (`git` или `Go`) — скрипт остановится и подскажет команду
установки под вашу ОС.

## Сборка вручную

Из корня репозитория:

```sh
go build -o bin/tgit .
```

Или через Makefile (то же самое, для текущей платформы):

```sh
make build
```

Бинарник появится в `bin/tgit` (`bin\tgit.exe` при сборке на Windows).

### Кросс-компиляция под все платформы сразу

```sh
make cross
```

Соберёт бинарники под Linux, macOS и Windows (amd64 и arm64) в `dist/`:

```
dist/tgit-linux-amd64
dist/tgit-linux-arm64
dist/tgit-darwin-amd64
dist/tgit-darwin-arm64
dist/tgit-windows-amd64.exe
```

Кросс-компиляция работает с любой ОС-хоста (Go сам подставляет нужный `GOOS`/`GOARCH`), собирать
на самой целевой машине не обязательно.

## Запуск

После `./install.sh` — просто `tgit` в каталоге нужного git-репозитория.

Без установки, прямо из собранного бинарника:

```sh
./bin/tgit
```

(На Windows: `bin\tgit.exe`.)

`tgit --version` печатает версию и завершает работу без запуска TUI — удобно для проверки,
что установка прошла успешно.

## Первый запуск и вход через GitHub

При первом запуске (если токен ещё не сохранён) tgit сразу показывает экран входа со ссылкой
на создание Personal Access Token:

```
https://github.com/settings/tokens/new?description=tgit-cli&scopes=repo,read:user
```

- Кликните по ссылке (если терминал поддерживает) или нажмите `Ctrl+O` — откроется браузер.
- Создайте токен с правом `repo`, скопируйте и вставьте в поле ввода.
- `Enter` — токен проверяется через GitHub API и сохраняется в системном хранилище секретов
  (Keychain на macOS, Credential Manager на Windows, Secret Service/dbus на Linux; если оно
  недоступно — в файле конфигурации с правами `0600`).
- `Esc` — пропустить вход и работать локально: GitHub не обязателен для базовых git-операций,
  войти можно позже клавишей `g`.

## Горячие клавиши (главный экран)

| Клавиша  | Действие                          |
|----------|------------------------------------|
| `Tab`    | переключить панель (Ветки/Файлы)  |
| `r`      | обновить данные репозитория        |
| `g`      | войти в GitHub / сменить токен      |
| `Ctrl+C` | выйти                              |

## Разработка

```sh
go vet ./...      # статическая проверка
go build ./...    # сборка всех пакетов
```

Структура проекта:

```
install.sh                — проверка зависимостей, сборка и установка в PATH
main.go                  — точка входа
internal/gitrepo/        — обёртка над системным git (статус, ветки)
internal/ghauth/         — проверка GitHub-токена, ссылка на его создание
internal/secret/         — кроссплатформенное хранение токена
internal/openurl/        — открытие ссылки в браузере по умолчанию
internal/ui/              — экраны на Bubble Tea (вход, главный экран, стили)
```
